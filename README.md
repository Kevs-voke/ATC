# Technical College of Abeldarl Website

The official website for the **Technical College of Abeldarl**, a TVET institution in Nyahururu, Laikipia County, Kenya. Its tagline, *"Modern Skills for Modern Careers"*, sums up the goal: give prospective students, parents, and partners a fast, clear, mobile-friendly place to learn about the college and apply.

🔗 **Live site:** [abeldarl.netlify.app](https://abeldarl.netlify.app)


## Features

- **Hero landing section** with clear **Apply Now** and **Contact Us** calls to action
- **Home, About, Programs, and Contact** sections, reachable from a sticky navigation bar
- **Programmes catalogue** showcasing the courses the college offers
- **Responsive design** that works on phones, tablets, and desktops
- **Smooth scroll animations** using AOS
- **Client-side routing** for fast navigation without full page reloads
